# 鹈鹕兜风 3D · 海滨晨骑

🦤 一只鹈鹕骑着薄荷绿自行车，在海滨晨风里兜风 —— 系列首次 3D 化。

**线上地址： https://yjj0339.github.io/pelican-3d/**

![扫码打开](qr-live.png)

## 玩法

- **按住屏幕 / 鼠标**：加速冲刺（围巾飞扬、翅膀扑扇、视野拉远）
- **拖动**：环绕视角；滚轮 / 双指：缩放
- **轻点鹈鹕**：摇铃铛「叮铃铃」，鹈鹕回头看你

## 技术

- **Blender 5.2 无头程序化建模**：鹈鹕（身体/喉囊/翅膀/尾羽/双腿）、自行车（车架/辐条轮/曲柄/挡泥板/铃铛）、海滨道具（棕榈/遮阳伞/海鸥/云/远山/海星/路牌），导出 GLB
- **Three.js 实时渲染**：两腿 IK 解算踩踏板、链条传动比联动轮速、正弦海浪 + 岸边浪花、布料感红围巾、盘旋海鸥、飘落花瓣、三层视差滚动布景
- 浅色主题 / 玻璃拟态 HUD / 移动端自适应

## 本地预览

```bash
node serve.js   # http://localhost:8912
```

## 目录

- `tools/make_pelican.py` — Blender 建模脚本（`blender -b --python` 运行）
- `tools/shot.js` — 无头截图验收（puppeteer-core + `window.__ready`）
- `assets/*.glb` — 建模产物
- `js/main.js` — 场景 / 动画 / 交互
