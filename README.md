# 🦩 鹈鹕骑行 · 3D 立体环游

> **线上地址：<https://yjj0339.github.io/pelican-3d/>**（手机扫码直达 👇）

![二维码](qr-live.png)

鹈鹕骑行系列第六代 · 首次 3D 化。Blender 精细建模 + Three.js 卡通渲染，
一只戴着红围巾的鹈鹕沿着海岸、樱花原野和落日葵海不停骑行。

## 玩法

| 操作 | 效果 |
|---|---|
| 拖动画面 / 滚轮 / 双指 | 转镜头 / 缩放 |
| 右上滑杆 或 W / S | 骑行速度 |
| 按住 🕊️滑翔 或 空格 | 张开翅膀飞一段（风线+叫声） |
| 🔔 车铃 或 B | 叮铃～鹈鹕张嘴回应 |
| 🎬 机位 或 C | 跟拍 / 侧拍 / 迎面 / 航拍 |
| 🌸 场景 或 1/2/3 | 海岸晨风 / 樱花原野 / 落日葵海 |
| 🎵 声音 或 M | 生成式音乐 + 环境音效 |
| 📸 拍照 或 P | 保存当前画面 |

## 技术栈

- **Blender 5.2 无头建模**（`tools/make_models.py`）：鹈鹕（头/下喙/双翅/尾/双腿 IK 骨骼/三节围巾）+ 自行车（转向/前后轮/曲柄/脚蹬）+ 15 种场景道具，导出 GLB
- **Three.js r170**：MeshToonMaterial 四档渐变卡通渲染 + PCFSoft 阴影
- **自定义 Shader**：天空渐变+太阳光晕、海面波浪+浪沫分带、路面车道线无限滚动
- **程序化动画**：矢状面两骨解析 IK 精确踩踏、翅膀四元数展开扑扇、围巾链式飘动、热气球/风车/海鸥/帆船环境动画
- **WebAudio 全合成**：车铃双击金属声、随风速滤波的噪声、海浪 LFO、鸟鸣、C-G-Am-F 生成式音乐盒
- **性能自适应**：帧率过低自动降 DPR / 关阴影；移动端 390px 布局适配
